Fig 3. No audited configuration reaches deep decoder-readout compression. (a) Global compression, C = 100(1 - kappa), for all 33 audited configurations: 22 hematopoietic, 10 neural-cortex and one lung-fibrosis configuration. Points are individual configurations; horizontal segments span the observed minimum-to-maximum range within each tissue. No configuration approaches the deep-compression threshold C > 50%, which lies outside the displayed scale. (b) Aggregate predictability ratio kappa for the same configurations against the cross-family G-VAE band (0.937-1.064) and the family-matched UNAGI band (0.915-1.086); the dashed line marks kappa = 0.5. Both calibrations preserve the 0/33 conclusion. Configuration-level values are reported in S1 Table.
