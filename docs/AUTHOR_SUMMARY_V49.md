# Author Summary V49

Gene-regulatory networks describe which transcription factors regulate which target genes, and single-cell variational autoencoders are increasingly given these networks as priors. A prior can be present in the model configuration without affecting training. We developed an audit that separates whether a prior is registered, whether it reaches the training objective, whether it reorganizes the latent space, and whether it improves reconstruction. In the released PG-UNAGI implementation, the prior-derived gene weights were assigned but never read by the loss. We then delivered a matched regulatory target-set weight directly into the reconstruction objective. In three VAE architectures, the real prior improved reconstruction of its named genes relative to a weight-matched random prior, while aggregate decoder predictability remained close to that of the no-prior model. These results show why a prior should not be credited from its presence in the architecture alone. The audit provides an upstream check before perturbation-response claims and does not replace testing against real perturbation data.
