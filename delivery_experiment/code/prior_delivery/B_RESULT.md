# Experiment B — 内容还是结构（2026-11-02）

## 一、原计划的第二因子作废：GCN 关不掉

原设计是 {真实先验, 度匹配打乱先验, 无先验} × {图卷积 on, off}。第一因子可行，
第二因子**在这个代码库里不是自由因子**：

`run_arm.py --gcn off` 会走 `Plain_VAE`，训练本身正常（29 秒 smoke 通过），但进入
UNAGI 的 iDREM 迭代后必然崩在时间图构建：

```
buildGraph.buildEdges → connectNodes → RuntimeError: No edges found between stage 1 and stage 2
```

原因是 `connectNodes` 要求某个簇对的距离显著低于全体距离的均值
（`pval = Φ(min d; mean d, sd d) < cutoff`）。Plain 编码器给出的逐阶段表示没有这种
左尾离群，所以一对边都建不出来。把 cutoff 从 0.05 调到 0.01 只会更早失败（0→1 就崩）。

**结论：图编码器不是可切换的架构选项，而是这套流程能跑起来的前提。**
强行放宽 cutoff 到 0.5 虽能建边，但那已经不是"最近的阶段对"，会改掉流程语义。
所以 B 的第二因子作废，9 个单元的运行已于第一个单元失败后停止，临时目录已清理。

## 二、第一因子：内容 vs 结构（用已有臂，无需新训练）

三水平内容因子，同一数据、同一预算（20×、45 轮）、三个种子：

| 臂 | 含义 |
|---|---|
| `empty_e45` | 无先验（该臂 `disable_tf_prior=True`，即文献里说的"功能上等于无先验"） |
| `shuffled` | 度匹配打乱先验：支撑大小与度数序列相同，无生物学内容 |
| `real` | 人工整理造血先验，20× |

统计量：末端潜表示 Z 的协方差有效秩（参与比 `(Σλ)²/Σλ²`），与仓库自带
`audit_results.json` / `audit_vs_e45empty.json` 里记录的值逐位一致（已交叉核对）。

| 臂 | s42 | s43 | s44 | 均值 ± sd |
|---|---|---|---|---|
| 无先验 | 3.114 | 2.659 | 2.420 | **2.731 ± 0.353** |
| 打乱先验 | 3.490 | 2.578 | 3.028 | **3.032 ± 0.456** |
| 真实先验 | 4.532 | 3.465 | 3.155 | **3.718 ± 0.722** |

相对无先验：打乱 +11.0%，真实 **+36.1%**；内容增量 +0.686，**相当于结构效应的 228%**。
逐种子看，真实先验 > 无先验在 **3/3** 个种子上成立（+1.418 / +0.806 / +0.735）；
打乱 > 无先验只有 2/3（+0.376 / −0.081 / +0.608）。

## 三、这与论文的写法不一致，必须先对上口径

论文 3.2 与 Synthesis 说的是「先验注入使潜空间**压缩**」（有效秩从 iter_0 到 iter_4 下降，
16/19 个配置方向为负），而这里是**末端水平**的横截面比较，结论是**先验把秩抬高**、
且**内容比结构作用更大**。两句话不是同一个量：

- 论文的量 = 同一运行内 iter_0 → iter_4 的**变化**；
- 这里的量 = 不同臂在**末端**的秩水平。

两者可以同时为真（先验臂起点更高、下降更多，末端仍高于对照），但**不能互相替代**。
在把 B 写进论文之前，必须先算出 iter_0 → iter_4 的逐臂变化，与论文的 Δlog(PR) 对齐；
否则会造出"论文说压缩、附录说升高"的直接矛盾。

**另外一点也该记下**：若末端比较成立，那么"content-agnostic"（内容无关）这条就与
+36% vs +11% 的对比不一致——内容至少贡献了结构效应的两倍。这条与 A 的结果方向一致
（A 也提示内容可测），值得合并成一条待核结论。
