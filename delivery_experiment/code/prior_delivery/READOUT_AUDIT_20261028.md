## 0. 先更正我自己的一个错误

我上一轮说"我们从没动过支撑比（n_s），而那是理论里的主旋钮"。**这是错的。**
`prior_delivery_runs/support/` 里早就有支撑阶梯：5× 剂量、3 seed、五臂：

| 臂 | 支撑（占转录组） | κ-C(W) | κ-C(Z) |
|---|---|---|---|
| empty | 0 | 1.0000 | 1.0000 |
| k203 | 203（1.0%） | 0.9974 ± 0.0097 | 0.978 ± 0.052 |
| k1000 | 1,000（4.9%） | 1.0014 ± 0.0045 | 1.032 ± 0.139 |
| k2027 | 2,027（9.9%） | 1.0004 ± 0.0072 | 1.085 ± 0.077 |

**支撑扩十倍，聚合读数动 0.3%。** 这与式 1 一致：2,027 × 0.0086 / 5,536 = 0.31%。
所以它不是"漏测的旋钮"，而是**界限的第三个实测点**——已补进 paper3 §4，标题从
"two independent routes" 改为 "three"。

这条更正也让 paper3 变强了：剂量、时长、支撑三条独立的轴，都指向同一个结论。

## 1. 交叉验证：样本内那个数被高估了三分之一

`pergene_fit.py::per_gene_r2` 用 `Ridge.fit` 之后对**同一批细胞** `predict`。
五个 headline 数字（+0.00861、天花板 +0.0145、0.01572 = 0.00861 + 0.00711）全部是样本内。

5 折交叉验证后（20×，45 加权 epoch，3 seed 均值）：

| | 样本内 | 5 折 OOF | kNN（非线性） |
|---|---|---|---|
| real 在自名基因上 | +0.00879 | **+0.00641** | +0.00565 |
| shuffled 在自名基因上 | +0.00174 | **+0.00426** | +0.00221 |
| **real − shuffled** | **+0.00705** | **+0.00215** | +0.00344 |

**"减去基线后的改善"这个量在留出集上缩到三分之一，而且 seed 42 反号**
（real +0.00065 vs shuffled +0.00991）。也就是说：**这个统计量是全篇最弱的量**，
不是最强的。它在样本内看起来干净，是因为样本内共享了拟合的乐观项。

## 2. 交叉支撑 DiD：真正被确定下来的是交互项

"每个臂都改善了自己那 203 个基因"不构成内容证据——被要求拟合的基因当然拟合得更好。
决定性问题是：**real 先验对 real 基因的提升，是否大于 shuffled 先验对同一批基因的提升。**

| | real 对 real 基因 | real 对 control 基因 | shuffled 对 real 基因 |
|---|---|---|---|
| 5 折线性（3 seed 均值） | **+0.00641** | +0.00060 | **−0.00601** |
| kNN 非线性（3 seed 均值） | **+0.00565** | +0.00058 | **−0.00239** |

- **shuffled 先验在 6/6 个 seed×读数里，把 real 命名的那些基因的读数压低了**
  （−0.0004 到 −0.0137），同时抬高自己的基因。一个"内容无关"的干预不是中性的，
  它对自己认错的基因有代价。
- DiD = (real_on_real − shuf_on_real) − (real_on_shuf − shuf_on_shuf)，
  3/3 为正：线性 +0.0064 / +0.0165 / +0.0253；kNN +0.0092 / +0.0111 / +0.0088。
- 基因级置换零分布（20,000 组同尺寸随机基因对）：**p = 0.0098 / <0.0001 / 0.0019**
  （线性），kNN 三 seed 全 p < 0.0001；**z = +2.6 到 +8.0**。

**3 个 seed 不能分辨均值差，但 20,527 个基因能分辨交互项。** 这正是内容主张真正依赖的量。
这条从"3/3 同向 + 大于 s.d."升级为"基因级置换 p < 0.01"，是零新训练能拿到的最大一级证据。

## 3. 非线性读数：结论保住了，而且它比线性更稳

kNN（k=15，Z 空间近邻均值，同折同划分，不做任何线性假设）：

- 整体读出 R² 略高于线性（0.1892 vs 0.1913 量级，逐 seed 一致）
- **内容交互项在 3/3 seed 复现，z 比线性路径更高**（+4.2 / +5.5 / +4.3）

所以"谱看不见局部效应"不是线性仪器的产物。这条也顺手回答了"你们只用线性探针"的质疑。

## 4. 先验不带方向：一半的方向性 null 是定义出来的

`run_arm.py` 全文没有 sign 处理。TRRUST 的 Mode 列被丢弃。审计结果：

| 量 | 值 |
|---|---|
| TRRUST 全库边数 / 有方向的边 | 9,396 / **54.0%**（Act 3,149，Rep 1,922，Unknown 4,325） |
| 触及 203 个审计基因的边 | **3,726**（Act 1,281，Rep 778，Unknown 1,667） |
| 其中已知方向的基因 | 160 / 203 |
| **同时收到激活与抑制边的基因** | **83** |
| 被多条边命中的基因 | 171 |

**203 个正标量要吞掉 3,726 条带符号的边，其中 83 个基因的符号本身是冲突的。**
乘性似然权重非负，结构上不可能携带符号。所以"先验没有组织潜空间方向"有一半是
**算子的性质**，不是生物学的性质——已写进 paper3 的 Limits，措辞明确到不会被误读。

要带方向，必须换进入路径（符号约束 decoder / 方向性损失），不是换权重向量。

## 5. 文献侧：字段报的是"增益"，不是"值"

查 LiVAE（Front Genet 2025）摘要，它把同一族指标的提升写成区间：
**manifold dimensionality 0.123–0.467、participation ratio 0.149–0.761、noise resilience 0.184–0.712**。

三件事随之成立：

1. **没有人用 50% 阈值。** 字段的用法是"越高越好"，报的是 Δ，不是绝对值。
   所以我们的批评不能写成"那个 50% 带不可达"——那是 κ-C 自己的定义，不是字段惯例。
2. **但同一个错误仍在**：报 Δ 而不给零假设、不给内容匹配对照。0.123–0.467 这种量级
   在结构正则化下唾手可得。
3. **量级差了一个半到两个数量级**：一个 GRN 先验能买到的交互项是 **0.006**，
   而字段报告的"几何增益"是 **0.12–0.47**。这个比值本身就是一个论证：
   那些增益不可能来自基因身份，只能来自正则化或架构。

## 6. GAN-off 对照：处方成立，而且把 B1 从"测不出"变成"测得出来"

P3 §6 给读者的处方是"关掉对抗分支、训到收敛"。这条从未被检验。现在跑了两个
**同配置**的无对抗臂（λ=0.1、real 基、30+15 epoch、同 seed），再加一个 perm 臂：

| 设置 | A | 复现差 |
|---|---|---|
| 含 GAN | 0.4682 / 0.7515 | **0.2833** |
| **关 GAN** | 0.7809 / 0.7780 | **0.0029** |
| 低噪声下 perm 基 | **0.7706** | — |

三件事：

1. **噪声确实来自对抗分支**，缩小 **98 倍**；同一段代码、同一份数据，只改一个布尔。
2. **关掉对抗后 A 反而更高**（0.78 vs 0.47/0.75）——惩罚项此前在和判别器抢同一个 decoder。
   这本身是一条可写的结论：对抗训练会部分抵消几何约束。
3. **内容效应现在可分辨，而且很小**：ΔA(real − perm) = **+0.0088**，约 4.3 倍复现差，
   但只有 $A$ 的 1.1%，而 λ 单独能把 $A$ 从 0.158 推到 0.969。

**所以 B1 的结论从"没能力回答"变成"能回答，答案是小"**：几何由约束**强度**主导，
不由基因**身份**主导。这与 §7.8 的基方差审计（GRN 基只比同秩随机高 1.2–1.35 倍）
互相印证，只是这次从算子一侧看到。

## 8. 放大（零训练）：把分母去掉，效应从 1.1% 变成 19.4%

`+0.0088` 是"每臂拿自己的基算 A"——自我参照量。每个臂都在最小化自己的 (1−A)，
所以两个臂都把自己的 A 顶到 0.78 附近；它测的是**约束咬得多深**，不是**咬向哪里**。

让每个 decoder 同时在两个基上打分（同一份 J，训练噪声完全消掉）：

| 臂 | A_C | A_P | 组内差 |
|---|---|---|---|
| real_1 | 0.7139 | 0.6325 | **+0.0814** |
| real_2 | 0.7053 | 0.6233 | **+0.0820** |
| perm | 0.6495 | 0.7051 | **−0.0556** |

- 交互项 **+0.137 = A 的 19.4%**；两 real 复制品散布 **0.00066**（约 200× 信噪）
- 相对 +0.0088（1.1%）：**放大 15 倍**
- top-32 版本：交互 +0.046，real/perm 比 > 1.6

**结论必须拆成两句**：

1. **约束满足得如何，与内容无关**（任何同秩基都到 0.78）；
2. **几何落在哪个子空间，由内容决定，且很强**（19.4% 的 A）。

这条比原来的 null 硬，因为它同时解释了**为什么**文献里"prior 改善了 geometry"的说法
看起来成立：**用自己的对齐分评估结构化 decoder，结构上看不见内容。**

### 顺带一个基审计事实
1,999 个 TRRUST 覆盖基因里，**231 个（11.6%）在本数据集中方差为零**——完全不表达。
注释基有约八分之一建在模型从来看不到的基因上。第一次跑表达基时正因为这 231 行导致
两个臂的支撑不一致，已修正为两边都只保留 1,768 个非零行。

## 9. 基的来源（预注册后跑）：P2 对，P1/P3 错——结果是一个夹逼

把同一算子指向数据自己的方向（top-32 主成分，占覆盖块 57.9% 方差；对照 = 同值随机分配，
支撑与秩锁定在 1,768 个非零行）：

| 臂 | 训练时 A（自己基） | 在表达基上的 A_C / A_P | 组内差 | 覆盖块 R² |
|---|---|---|---|---|
| expr/real | **0.4113** | 0.4012 / 0.2095 | **+0.1918** | 0.18691 |
| expr/perm | **0.7152** | 0.0972 / 0.6174 | **−0.5202** | 0.18986 |
| annot/real ×2 | 0.7809 / 0.7780 | — | +0.0814 / +0.0820 | 0.18891 / 0.18797 |
| annot/perm | 0.7706 | — | −0.0556 | 0.18819 |

**预注册三条，错两条**：P1（交互项同量级）实际 +0.712，大 5 倍；P3（expr 族 real > perm）
实际 −0.00295，方向相反。**只有 P2 对**，而 P2 是唯一能翻盘的那条。

### 9.1 结果不是"没用"，是夹逼

看训练时 A 那一列，三种基排出反直觉顺序：

| 基 | 满足约束的代价 | A（自己基） |
|---|---|---|
| 注释模块（5.9% 方差） | 几乎免费 | 0.78 |
| 表达基的置换（3.2%） | 免费 | 0.72 |
| **表达导出 PCA（57.9%）** | **昂贵** | **0.41** |

> **指向数据不用的方向：免费且无害。指向数据真用的方向：昂贵到优化器让步
> （0.78 → 0.41）。两种情况下逐基因读数都不动。**

这一条比前面所有 null 都强，因为它是**机制**而不是缺失：内容被搬动了（+0.19 与 −0.52
是全文最大的几何效应），但搬动的位置拿不到读数；而唯一能拿到读数的地方，优化器不肯去。

### 9.2 顺带证实的一件事
1,999 个注释覆盖基因里 **231 个（11.6%）在本数据集方差为零**；两个基都只保留 1,768 个
非零行，支撑与秩严格匹配。这是"注释基有一部分建在模型看不到的基因上"的直接证据。
